# Erubinyl.is-a.dev source code

I think something just ruptured from the insides of my cranium to achieve something like this.

## Killing 2 birds with 1 stone

This repository is oddly two of my projects combined together inside a single repository.
As the reasoning to that is solely because I did not intend for anyone to adopt this "framework" of mine.
However! if you are curious, or just want to use it, go ahead, it's FOSS.

This so called "framework" is still in need for more brainstorming, and a little of *me time* for it to be polished.

### Navigating through the labyrinth

The `/source` folder contains the original `.nwve` files that acts as a blueprint for the entire website,
where as `/resources/javascript/framework` contains the framework that constructs the blueprints.
The final product of the website is found at `/deployment`, however the contents has been minimised, and is practically hard to read.

### Bringing contributions (as Pull requests), or Ideas to this Repository

Have an Idea or saw a piece of code that you want to change for the better?
You could help this Repository and I will gladly be thankful to you for it.

- **For bringing in Commit changes, as a form of Pull requests,** please keep patience as I work on your Pull request.
  For what you can do, you could [Fork this repository](https://github.com/Erubinyl/is-a.dev/fork), Insert a few commits regarding your matter (Keep other matters separate, *to make it easier for the both of us*).
  And open up a humble Pull request. \
  \
  More about Forking, and making a Pull request could be found over at [GitHub's documentations](https://docs.github.com/en/get-started/quickstart/contributing-to-projects).
- **For bringing in Feedbacks, Issues, or Ideas**, please refrain from aggression and tomfoolery.
  For what you can do, you could open up a [New Issue](https://github.com/Erubinyl/is-a.dev/issues/new/) inside the Repository, and cherry-pick the correct Label for your Matter.

Personally, my GitHub repositories are always open for criticism in a form of Code, Vision, or Revision change that I am willing to accept.
Please keep your tone and refrain from being aggressive, not only to me, but to everyone outside too, and be a better person too <3
